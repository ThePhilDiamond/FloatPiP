# The FloatPiP name and logo

"FloatPiP" and the FloatPiP logo identify the official project and the builds published on this repository's Releases page. The code licenses (AGPL-3.0-only, or a commercial license) cover the code, not the name or logo.

You are welcome to fork FloatPiP. If you publish a fork or your own build:

- give it a different name and icon, so nobody mistakes it for the official app;
- you may say it is "based on FloatPiP" and link back here;
- don't present it as an official FloatPiP release, or imply the project endorses it.

Writing about FloatPiP, linking to it, and using the name to refer to the official project is fine and doesn't need permission.

Apple, Mac, and macOS are trademarks of Apple Inc. FloatPiP isn't made, endorsed, or supported by Apple. FloatPiP's documentation may name other companies' products (such as video-calling apps) only to say which program is which; those names belong to their owners, and naming them doesn't mean their makers endorse FloatPiP.
