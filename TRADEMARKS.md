# The Window Raft name and logo

"Window Raft" and the Window Raft logo identify the official project and the builds published on this repository's Releases page. The code licenses (AGPL-3.0-only, or a commercial license) cover the code, not the name or logo.

You are welcome to fork Window Raft. If you publish a fork or your own build:

- give it a different name and icon, so nobody mistakes it for the official app;
- you may say it is "based on Window Raft" and link back here;
- don't present it as an official Window Raft release, or imply the project endorses it.

Window Raft was called FloatPiP before version 0.2.0; what this page says applies to that name and its logo too.

Writing about Window Raft, linking to it, and using the name to refer to the official project is fine and doesn't need permission.

## Other companies' names

Apple, Mac, and macOS are trademarks of Apple Inc. Window Raft isn't made, endorsed, or supported by Apple. Window Raft's documentation may name other companies' products (such as video-calling apps) only to say which program is which; those names belong to their owners, and naming them doesn't mean their makers endorse Window Raft.
